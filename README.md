# PDF to Layers

Плагин для Photoshop 2022+ (UXP), который импортирует страницы PDF в отдельные слои.

- Режим: **растр** (пиксельный слой) или **смарт-объект** (встроенная страница PDF, вектор сохраняется).
- Диапазон страниц: `1-5, 8, 10-12`, `4-` (с 4-й до конца), пусто = все.
- Куда: **новый документ** (300 ppi, размер по самой большой странице) или **текущий документ** (его разрешение).
- Слои называются `Page N`, страница 1 сверху, все слои прижаты к левому верхнему углу.
- Весь импорт — один шаг истории (отменяется одним Ctrl+Z); отмена во время импорта откатывает изменения.

## Сборка

```bash
npm install
npm run build   # собирает src/ → plugin/main.js
npm test        # unit-тесты (без Photoshop)
```

`npm run watch` — пересборка при изменениях. `npm run icons` — перегенерировать иконки.

## Установка для разработки

1. Установите **UXP Developer Tool** из Creative Cloud.
2. `npm run build`.
3. В UDT: **Add Plugin** → выберите `plugin/manifest.json` → **Load**.
4. В Photoshop: **Plugins → PDF to Layers**.

## Сборка .ccx для установки

В UDT: меню плагина (•••) → **Package** → выберите папку. Получившийся `.ccx` устанавливается двойным кликом (через Creative Cloud).

## Как это работает

Страницы рендерит сам Photoshop через команду **Place** (`placeEvent` + `PDFGenericFormat`, дескриптор снят с записанного Action). `pdf-lib` читает только число страниц и их размеры (CropBox с учётом поворота), чтобы проверить диапазон, задать размер холста и вернуть масштаб 100 %, если Photoshop уменьшил страницу под размер холста. В режиме «Растр» смарт-объект после размещения растрируется.

Область обрезки страницы задаётся константой `PDF_CROP` в `src/psActions.js` (по умолчанию `cropBox` — страница как в Acrobat).

## Структура

```
plugin/            # то, что загружается в Photoshop
  manifest.json
  index.html       # панель (Spectrum UXP-виджеты)
  icons/
  main.js          # сборка (не в git)
src/
  index.js         # UI панели
  importer.js      # импорт внутри executeAsModal
  psActions.js     # batchPlay-дескриптор Place
  pdfInfo.js       # метаданные PDF (pdf-lib)
  pageRange.js     # парсер диапазона страниц
tests/             # jest
```
